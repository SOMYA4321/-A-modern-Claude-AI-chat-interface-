# 🤖 Claude AI Chat Interface

A modern and interactive **Claude AI web interface** built using **HTML, CSS, and JavaScript**, powered by **Puter.js** for real-time AI responses.

---

## 🚀 Features

* 💬 Real-time AI chat interface
* ⚡ Streaming responses (live typing effect)
* 🧠 Multiple Claude models support
* 🗂️ Conversation history (recent chats)
* 🎨 Clean & modern UI (dark theme)
* 📦 Code artifact preview (HTML, JS, etc.)
* 📥 Copy & download code snippets
* 🔐 Easy authentication with Puter.js

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript (Vanilla)**
* **Puter.js (AI Integration)**

---

## 📦 Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/your-username/your-repo-name.git
```

2. Open the project folder:

```bash
cd your-repo-name
```

3. Run the project:

* Simply open `index.html` in your browser
  **OR**
* Use Live Server (recommended)

---

## 🔐 Authentication Note

* On first use, a popup will appear for authentication
* Allow the popup to enable AI functionality
* If it fails:

  * Try Incognito mode
  * Disable ad blockers/extensions
  * Allow third-party cookies
